## 💡 核心理念

「今日todo」不是效率鸡汤，而是一种**基于认知科学的减法策略**。

### 为什么是 3 件？

人类工作记忆容量有限。心理学研究表明，大脑同时处理的信息单元通常不超过 **4-7 个**。当清单超过这个阈值时，大脑进入「超载状态」：

- ❌ **决策疲劳** — 每完成一项任务都消耗决策资源
- ❌ **注意力分散** — 未完成的任务持续占用认知资源
- ❌ **虚假完成感** — 列清单产生满足感，与实际产出脱节

**3 件原则**将任务数量控制在认知负荷的安全范围内，确保每件事都能获得足够的注意力。

---

## 📋 3 条核心规则

### 规则 1：只列 3 件
每日任务上限为 3 件。多出的任务归入「待转移清单」。

### 规则 2：区分「要做的」和「想做的」
- **要做的**（2 件）— 他人期待或责任驱动的工作
- **想做的**（1 件）— 个人成长或兴趣驱动的行动

### 规则 3：完成后才能加新任务
完成 1 件后，从待转移清单中补充 1 件。始终保持 3 件的任务存量，但不突破上限。

## 🎯 进阶应用

这个方法论可以向上延展：

| 层级 | 数量 | 内容 |
|------|------|------|
| **日 (今日todo)** | 3 件 | 每日任务 |
| **周 (周todo)** | 3 件 | 关键成果 |
| **月 (月todo)** | 3 件 | 核心目标 |

层级越往上，允许的任务数量越少，聚焦程度越高。

## 💬 常见问题

**Q：事情太多怎么办？**
A：排序。只选 3 件意味着必须放弃其他 87 件。放弃是必要的。

**Q：突发事件打乱计划怎么办？**
A：接受。突发事件是常态，计划的价值在于提供决策锚点。调整后重新选 3 件。

**Q：可以改成 5 件吗？**
A：可以，但违背了初衷。3 件的关键是**强制选择**，而非简单计数。
